# RU AI Unlocker

Универсальный инструмент для разблокировки популярных зарубежных сервисов (**ChatGPT, Claude, Gemini, Copilot, Spotify и тд** и др.) на **Windows**, **Linux** и **Android** через безопасный редирект в файле `hosts` — **без использования VPN и без замедления скорости интернета**.

Актуальная база хостов: [dns.malw.link](https://dns.malw.link)

---

## Возможности

- **Разблокировка в 1 клик**: мгновенное обновление файла hosts.
- **Встроенный редактор**: просмотр, поиск, добавление и удаление своих записей.
- **Безопасность**: автоматическое создание бэкапа перед каждым изменением с возможностью отката.
- **Сброс кэша DNS**: встроенная очистка DNS-резолвера системы.
- **Автопроверка обновлений**: проверка свежих версий hosts и самого приложения через GitHub.

---

## Быстрый старт

### Windows
1. Скачайте **`RUAIUnlocker.exe`** из папки `windows/` или раздела [Releases](../../releases).
2. Запустите от имени администратора.
3. Нажмите кнопку **«Обновить hosts из репозитория»**.

### Linux
Запустите одну команду в терминале, предварительно установив всё для линукса:
```bash
chmod +x ruaiunlocker.sh
sudo bash ruaiunlocker.sh
```


### Android


1. Установите модуль из релизов
2. Зайдите в ваш рут менеджер. установите модуль и перезагрузите устройство.
3. Установите приложение. Выдайте рут и пользуйтесь!
